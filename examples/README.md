This example comes from an [Adafruit tutorial.](https://learn.adafruit.com/led-matrix-sports-scoreboard) Copy the contents of the`src` directory to the `CIRCUITPY` drive and connect it to the LED matrices as defined in the previously mentioned tutorial.

`get_team_logos.py` needs to run on your host machine by running the following from the command line
```
python get_team_logos.py
```
Insure the packages in `requirements.txt` are installed before running. Copy the script's output to your `CIRCUITPY` drive.
